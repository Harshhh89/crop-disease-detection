# Crop Disease Detection Using Image Recognition

## Overview

Crop Disease Detection is an AI-powered web application that helps farmers and researchers identify crop diseases from leaf images. The system uses image recognition and machine learning techniques to analyze uploaded images and predict possible diseases.

## Features

- Upload crop leaf images
- Automatic disease detection
- Disease prediction with confidence score
- User-friendly interface
- Fast image processing
- Responsive design

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Python
- TensorFlow / CNN Model
